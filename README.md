# QM & MD Toolkits for CADD

A collection of quantum mechanics (QM) and molecular dynamics (MD) analysis toolkits for **Computer-Aided Drug Design (CADD)**.

## Repository Structure

### Post_MD_Analysis
Contains scripts and automations for the analysis of post-MD trajectory results.

*   [`prolif_run.py`](Post_MD_Analysis/prolif_run.py) — Protein-Ligand / Nucleic Acid-Ligand Interaction Fingerprint (IFP) analysis pipeline for MD trajectories. See [Post_MD_Analysis/README.md](Post_MD_Analysis/README.md) for details.

Additional QM toolkits will be added to this repository over time.
